# Assignment 11: Chinese Festivals TabView

#### About 

An iOS app that uses TabView to introduce three traditional Chinese festivals.

| Tab | Festival | Chinese |
|---|---|---|
| 1 | Spring Festival | 春节 |
| 2 | Qingming Festival | 清明节 |
| 3 | Duanwu Festival | 端午节 |
